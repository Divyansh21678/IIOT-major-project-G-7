Sheet: Employee Data. All data is synthetic (randomly generated with a fixed seed), so it contains no real employee information.

Column	Description
Emp ID	Unique employee ID (E1001 to E1300)
Name	Employee name
Department	Sales, Engineering, HR, Finance, Marketing, Operations
Job Role	Role within the department
Gender	Male / Female
Age	Age in years
Tenure (Yrs)	Years with the company
Annual Salary (INR)	Yearly salary
Performance (1-5)	Performance rating
Satisfaction (1-5)	Job satisfaction (1 = low, 5 = high)
Overtime	Yes / No
Status	Active / Left
Exit Date	Date of leaving (leavers only)
Exit Reason	Reason for leaving (leavers only)

The data was designed so that low satisfaction, overtime, short tenure, low pay and the Sales department raise the likelihood of leaving, so the charts show realistic patterns.
